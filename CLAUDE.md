Read technical.md before working on this repository: it explains the architecture, the
content files, the build, the tests and the editorial decisions. Keep it up to date when
you change how things work (and its "Known gaps" list when photos or texts are fixed).

- Edit content in content/, never the generated files (data/, locales/, fr/, en/, es/,
  sitemap.xml); then run `node tools/build.mjs` and `node --test tests/`.
- Docs and code comments in English. Ask before pushing to main.
